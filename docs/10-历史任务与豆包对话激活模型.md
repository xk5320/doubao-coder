# 14. 历史任务 ↔ 豆包对话 激活模型（设计计划）

> 目标：把「扩展本地历史」与「豆包对话列表」收敛成一个激活目标（ActiveTarget），
> 所有入口（历史点击、发送、旁观、恢复上次窗口、新建）走同一条激活链路。

## 1. 现状盘点

| 位置 | 存了什么 | 谁写 | 问题 |
| --- | --- | --- | --- |
| `panel.lastDesktopTitle` | 当前绑定的豆包对话标题 | 打开豆包历史 / 本地会话 / 恢复 | 与 sessionId 不同步；改名失效 |
| `globalState[doubao.lastDesktop]` | 上次窗口标题 | openDesktopChat | 面板每次打开都恢复，抢用户选择 |
| `session.desktopTitle` | 本地会话 ↔ 豆包对话 | 导入时 | 重名/改名匹配不准；可能缺失 |
| `panel.sessionId` | 当前本地会话 | 多处 | 打开豆包对话会重复建会话 |
| `watchRunningTask(title)` | 旁观目标 | 历史打开 / 回合后续跑 | 与激活目标解耦，靠子串判断 |
| `restoreAttempted` | 只恢复一次 | resolveWebviewView | 与用户操作竞争 |
| `lastAsk` | 询问卡去重 | 轮询 | 切对话后不清空 |

典型乱象：点历史后豆包没切、发送落到别的任务、旁观写入别的任务结果、恢复覆盖用户选择、同名串台。

## 2. ActiveTarget 单一状态

```ts
type ActiveTarget =
  | { kind: 'desktop'; title: string; sessionId?: string; updatedAt: number }
  | { kind: 'local'; sessionId: string; desktopTitle?: string; updatedAt: number }
  | { kind: 'none'; updatedAt: number };
```

规则：

1. 唯一真值：面板只认 `activeTarget`，`lastDesktopTitle` 改为派生值。
2. 持久化到 `workspaceState`（带 updatedAt）；恢复只在“本次会话尚未激活”时执行。
3. 所有入口统一走 `activateTarget(target, source)`：
   - 标题归一化（trim、全角空格、连续空白压缩）；
   - 豆包列表匹配：精确 → 忽略大小写/空白 → 前缀，禁止任意子串；
   - `openDesktopConversation(index)` 后用 `readDesktopTitle()` 复核；
   - 复用同 `desktopTitle` 的本地会话，没有才导入；
   - 中止旧旁观/轮询/询问卡，清 `lastAsk`；
   - 更新并持久化 `activeTarget`，`postState()`。
4. 发送前 `ensureActiveTargetForSend()`：desktop/local(带标题) 先校验并切回，找不到则阻断发送并提示；
   新对话发送成功后用豆包返回标题回填会话与 activeTarget。
5. 旁观 `watchRunningTask` 只接受 activeTarget；每轮归一化标题**全等**校验，不一致立即停止且不推内容。
6. 恢复上次窗口：仅当 `kind === none` 且用户未操作时执行；先校验对话仍存在，否则清空并提示。
7. 历史列表：豆包对话项点击 → activate desktop；本地项有 desktopTitle → 激活并切换，没有则只回放并清绑定；
   列表加载做一次对账，失效项标「对话已不存在」。
8. 新建对话/新任务：`activateTarget({kind:none})`，清绑定，不触发恢复。

## 3. 状态迁移

```text
none --点豆包历史--> desktop --发送/旁观--> desktop
none --点本地历史(有标题)--> local(+desktopTitle) --> 切豆包，等同 desktop
local --发送成功拿到标题--> local + desktopTitle
desktop --新建对话--> none
desktop --豆包被切走--> watcher 停止（保持 desktop，标记失联，发送前切回或阻断）
```

## 4. 边界与异常

| 场景 | 期望 |
| --- | --- |
| 豆包会话改名 | 按列表标题重新匹配，失败提示重绑 |
| 两个同名对话 | 禁止子串；精确命中多个取最近更新并记日志 |
| 旁观中切换 | 立即 abort，不落 blocks |
| 打开历史时豆包正忙 | 先切对话，发送前再校验 |
| 面板重开与用户点击竞争 | 比较 updatedAt，用户操作优先 |
| 本地会话无 desktopTitle | 只回放；首次发送走新对话，成功后回填 |

### 阶段 4：联调与发布

## 6. 验收标准

1. 任意历史点击后 1 秒内切到对应对话；
2. 发送永不落到非激活对话（找不到则阻断提示）；
3. 旁观中途切换对话，面板不出现别的任务内容；
4. 面板重开不覆盖用户本次选择；
5. 同一豆包对话只对应一个本地会话；
6. `doubao.log` 每次激活/阻断都有「激活目标」记录。
