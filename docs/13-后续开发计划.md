# 13. 后续开发计划（0.46–0.50）

## 0.46 审阅增强
- Diff 逐块接受/拒绝（按行分块，可勾选）；
- 多提案队列：可同时存在多个待审阅改动，逐个处理/全部接受；
- 撤销栈：每次接受可单独回滚（最多 20 条）。

## 0.47 闭环增强
- 接受改动后自动运行构建/测试，失败自动把输出回喂豆包；
- 上下文可视化：输入框上方显示本次上下文清单与 token 估算。

## 0.48 稳定性
- CDP 断开自动重连、端口占用检测、错误分类与一键修复；
- 多根工作区会话/标签/上下文隔离。

## 0.49 任务与来源
- 后台任务中心（进度/完成通知，不抢当前标签）；
- 回答来源面板（文件:行汇总，可跳转）。

## 0.50 发布与生态
- GitHub Actions：打 vsix + 自动发布 + Release Notes；
- MCP 模板一键添加。

## 验收
- 每个版本 npm test 全绿、打包安装、更新 CHANGELOG；
- 审阅/撤销/验证在真实使用中可回退，不丢代码。
